# Pembukaan 
## TCP three-way handshake  
The TCP 3-Way Handshake adalah proses yang dilakukan oleh Transmision Control Protocol (TCP) untuk memastikan koneksi yang dapat diandalkan antara sebuah client dan sebuah server sebelum transmisi data dimulai.
